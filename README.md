## 🌟 نظرة عامة (Overview)

**ReWord** هو نظام متكامل وحديث لإدارة كلمات المرور وتأمين الهوية الرقمية، تم تصميمه وبناؤه وفق مبدأ **المعرفة الصفرية (Zero-Knowledge Architecture)** على غرار أشهر الأنظمة الأمنية العالمية (مثل Bitwarden و 1Password).

يعمل النظام بشكل كامل بدون إنترنت (**Offline-First**) كتطبيق ويب تقدمي (**PWA**)، ويتزامن سحابياً وفورياً ككتل بيانات مشفرة تماماً عبر **Cloudflare Workers & KV**، مع **إضافة لمتصفح جوجل كروم (Chrome Extension - Manifest V3)** تقدم ميزة **الملء التلقائي (Autofill)** الذكي داخل صفحات تسجيل الدخول في المواقع والتطبيقات بضغطة زر واحدة.

> [!IMPORTANT]
> **مبدأ المعرفة الصفرية (Zero-Knowledge):** لا يتم إرسال كلمة المرور الرئيسية أو أي بيانات غير مشفرة إلى أي سيرفر أو جهة خارجية على الإطلاق. التشفير وفك التشفير يتم محلياً 100% داخل معالج جهازك فقط باستخدام واجهة المتصفح القياسية `Web Crypto API`. السيرفر لا يرى سوى كتل نصوص مشفرة لا يمكن قراءتها.

## 🧠 كيف يعمل المشروع بالتفصيل؟ (آلية العمل والمعمارية)

```
┌────────────────────────────────────────────────────────┐
│             جهاز المستخدم (Client-Side)                │
│                                                        │
│  [ المتصفح / PWA ]   أو   [ إضافة كروم Extension ]     │
│        │                          │                    │
│   (IndexedDB)                 (Autofill)               │
│        │                          │                    │
│        ▼                          ▼                    │
│    Web Crypto API: PBKDF2 (310k) + AES-256-GCM         │
│  (التشفير وفك التشفير يحدث هنا فقط داخل جهازك!)       │
└───────────────────────────┬────────────────────────────┘
                            │
              يرسل فقط بيانات مشفرة بالكامل
                   (Encrypted Blob)
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│             سيرفرات Cloudflare (Serverless)            │

│        ▼                                               │
│   [ Cloudflare KV: vaults ]                            │
│   (تخزن كتل البيانات المشفرة دون معرفة محتواها أبداً)  │
└────────────────────────────────────────────────────────┘
```

### 1. طبقة التشفير الفائق (The Cryptography Engine):
* **كلمة المرور الرئيسية (Master Password):** لا تغادر جهازك نهائياً ولا تُخزن في أي قاعدة بيانات سحابية.
* **اشتقاق المفتاح (Key Derivation):** عند إدخال كلمة المرور، يتم تمريرها إلى خوارزمية **PBKDF2 مع SHA-256 بعدد 310,000 دورة تكرار** (وهو المعيار الصارم الموصى به من OWASP) مع Salt عشوائي بحجم 32 بايت لاشتقاق مفتاح تشفير عالي القوة بحجم 256 بت.
* **التشفير المتماثل:** تُشفر بيانات الخزينة بالكامل باستخدام **AES-256-GCM** مع `Initialization Vector (IV)` عشوائي (12 بايت) لكل عملية حفظ، مما يمنع حتى هجمات المقارنة الإحصائية.
* **معرّف المزامنة المشفر (Hashed Sync ID):** معرّف المزامنة لا يُرسل بصيغته الأصلية، بل يتم تجزئته عبر **SHA-256 Hash** (`reword:v1:${syncId}`) حتى لا يستطيع السيرفر ربط البيانات بهوية المستخدم.

### 2. طبقة السحابة (Cloudflare Worker & KV):
* الـ Worker هو سيرفر خفيف فائق السرعة وبدون خوادم تقليدية (`worker/index.js`).
* **دوره:** استلام الكتلة المشفرة وحفظها في قاعدة بيانات **Cloudflare KV** السحابية الموزعة عالمياً.
* **منع التعارض (Conflict Detection):** يقارن الـ Worker الطوابع الزمنية (`ts`) مع الخزائن المحفوظة لضمان عدم الكتابة فوق تعديلات أحدث تم إجراؤها من جهاز آخر.

### 3. طبقة إضافة كروم والملء التلقائي (Chrome Extension Autofill):
* تم بناؤها بأحدث معايير إضافات المتصفح **Manifest V3**.
* يعمل سكربت الخلفية (`background.js`) كـ Service Worker يحتفظ بنسخة الخزينة في ذاكرة الجلسة الآمنة (`chrome.storage.session`) مع نظام قفل تلقائي ذكي بعد فترة خمول.
* سكربت الحقن (`content.js`): يفحص شجرة العناصر (DOM) في أي موقع تفتحه، ويكتشف حقول تسجيل الدخول ويحقن أيقونة ReWord التفاعلية داخل الحقل.
* عند النقر، يقترح الحسابات المطابقة للنطاق الحالي، ويملأ البيانات مع إطلاق أحداث `input` و `change` لتتوافق تماماً مع أطر العمل الحديثة (React, Vue, Angular).

## 📖 دليل الاستخدام الكامل (User Guide)

### أولاً: استخدام موقع الويب (ReWord Web App / PWA)

#### 1. إنشاء خزينتك لأول مرة:
1. افتح الموقع عبر الرابط: [reword-app.pages.dev](https://reword-app.pages.dev/).
2. اختر **"إنشاء خزينة جديدة"**.
3. أدخل **كلمة مرور رئيسية قوية** (تأكد من حفظها جيداً، فلن يتمكن أحد من استعادتها إن نسيتها).
4. يمكنك كتابة تلميح (Hint) اختياري لمساعدتك على تذكرها لاحقاً.
5. في قسم المزامنة (اختياري لكن يُنصح به):
   * أدخل **Sync ID** خاصاً بك (مثلاً: كود أو اسم فريد تفضله).
   * رابط الـ Worker سيكون مكتوباً مسبقاً: `https://reword-vault-sync.moasaar6.workers.dev`.
6. اضغط **"إنشاء الخزينة"** للدخول فوراً إلى واجهة حساباتك.

#### 2. إضافة وإدارة الحسابات:
* اضغط على زر **"+ إضافة موقع"**.
* اكتب اسم الموقع أو التطبيق (مثل: Google, Facebook, GitHub)، ورابطه، واسم المستخدم أو البريد، وكلمة المرور.
* يمكنك استخدام زر **توليد كلمة مرور قوية ⚡** لإنشاء كلمة مرور عشوائية معقدة.
* اضغط **حفظ** ليتم تشفير البيانات ومزامنتها فوراً.

#### 3. استخدام الموقع بدون إنترنت (Offline Mode):
* الموقع يدعم تقنية **PWA** بالكامل؛ يمكنك تثبيته كتطبيق على سطح المكتب في الويندوز أو الماك أو على شاشة هاتفك الرئيسية (Install App).
* بفضل **IndexedDB** و **Service Worker (`sw.js`)**، يمكنك فتح الموقع والوصول لكل كلمات مرورك حتى أثناء انقطاع الإنترنت تماماً.

#### 4. ربط ومزامنة الخزينة على جهاز آخر:
* إذا فتحت الموقع من جهاز جديد (كمبيوتر العمل، أو هاتفك المحمول):
* اختر **"ربط خزنة موجودة"**.
* أدخل نفس الـ **Sync ID** ونفس **كلمة المرور الرئيسية**.
* سيقوم التطبيق بجلب خزينتك المشفرة من السحابة وفك تشفيرها وعرضها محلياً في ثوانٍ.

#### 5. النسخ الاحتياطي والاستيراد:
* **تصدير الخزينة المشفرة:** يمكنك تحميل ملف `.reword` مشفر بالكامل لحفظه في أي مكان آمن.
* **استيراد من متصفح أو تطبيق آخر:** يدعم التطبيق استيراد كلمات المرور عبر ملفات **CSV** (من Chrome أو Bitwarden).
* **تصدير Excel:** إمكانية تصدير بياناتك في ملف **Excel XLSX** منسق ومبوب.

---

### ثانياً: استخدام إضافة المتصفح للكمبيوتر (Chrome Extension)

#### 1. تثبيت الإضافة على جوجل كروم (أو Edge أو Brave):
1. افتح المتصفح وتوجه إلى العنوان:
   ```text
   chrome://extensions/
   ```
2. قم بتفعيل زر **"وضع مطور البرامج" (Developer mode)** في أعلى يمين الصفحة.
3. اضغط على زر **"تحميل حزمة غير مضغوطة" (Load unpacked)**.
4. حدد مجلد [`extension`](./extension) من داخل ملفات المشروع على جهازك.
5. ستظهر أيقونة **ReWord** فوراً في شريط أدوات المتصفح، قم بتثبيتها (Pin) لتسهيل الوصول إليها.

#### 2. ربط الإضافة بخزينتك:
1. اضغط على أيقونة الإضافة في شريط المتصفح.
2. ستظهر لك شاشة **"ربط الخزينة السحابية"**.
3. أدخل نفس الـ **Sync ID** وكلمة المرور الرئيسية (رابط الـ Worker مكتوب مسبقاً).
4. اضغط **"جلب وفتح الخزينة"** لتفتح لك خزينتك فوراً.

#### 3. تجربة الملء التلقائي (Autofill) في المواقع:
* **الطريقة الأولى (من داخل حقل الإدخال):**
  * توجه إلى صفحة تسجيل دخول في أي موقع (مثل `facebook.com` أو `github.com`).
  * ستلاحظ ظهور أيقونة درع **ReWord** البنفسجية الأنيقة داخل حقل تسجيل الدخول.
  * انقر على الأيقونة أو الحقل لتظهر لك قائمة منسدلة فورية بحساباتك المحفوظة لهذا الموقع.
  * اختر الحساب، وسيتم ملء اسم المستخدم وكلمة المرور تلقائياً!
* **الطريقة الثانية (من نافذة الإضافة السريعة):**
  * افتح الإضافة وأنت في صفحة الموقع، ستجد قسماً في الأعلى بعنوان **"الموقع الحالي"**.
  * اضغط على زر **"تعبئة ⚡"** ليتم ملء بيانات الصفحة المفتوحة فوراً وإغلاق النافذة.

#### 4. حفظ حساب جديد لأي موقع بضغطة زر:
* عند فتح الإضافة في أي موقع، اضغط على **"+ إضافة حساب جديد"**.
* ستلاحظ أن اسم الموقع والرابط يتم كتابتهما تلقائياً بناءً على الصفحة المفتوحة.
* أدخل اسم المستخدم وكلمة المرور واضغط حفظ ليتم تشفير الحساب وإضافته ومزامنته فوراً.

```text
├── core.js                 # محرك التشفير الرئيسي (Web Crypto)، IndexedDB، والمزامنة السحابية

├── style.css               # التصميم والأنماط الداكنة العصرية المتجاوبة
├── sw.js                   # Service Worker للعمل أوفلاين كـ PWA
├── manifest.json           # إعدادات تطبيق الويب التقدمي
├── icon.png                # الشعار الرسمي للتطبيق
│
├── worker/
│   └── index.js            # دالة Cloudflare Worker لمعالجة المزامنة والتخزين في KV
├── wrangler.toml           # إعدادات Cloudflare Wrangler وربط الـ KV Namespace
│
├── extension/              # إضافة متصفح جوجل كروم (Manifest V3)
│   ├── manifest.json       # تعريف الإضافة، الأذونات، وسكربتات الخلفية
```
